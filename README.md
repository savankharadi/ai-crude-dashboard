# AI Crude Dashboard

This project is a Next.js dashboard for crude futures and options intelligence, including:
- WTI free-data feed tile
- Groww token form
- buy/sell signal logic
- event triggers
- shareable snapshot route

## Repository
https://github.com/savankharadi/ai-crude-dashboard

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Production deployment note
The app is prepared for deployment to Vercel or a Dockerized Node server. For a live public URL, the project should be deployed to a provider like Vercel.
